feedback.correct: 정답입니다! 함수 안으로 전달되는 값을 받아주는 중매업자 같은 변수예요.

feedback.correct: 정답입니다! 기본적으로 인수는 함수에 정의된 매개변수의 순서대로 차례차례 들어갑니다.

question: 다음 코드를 실행했을 때 화면에 나타나는 출력은 무엇인가요?
code: |
  def combine(a, b):
      print(b + a)

  combine("파이", "썬")

  B. 썬파이
  C. a + b
  D. b + a
answer: B

feedback.correct: 정답입니다! 매개변수의 위치와 함수 내부에서 변수가 활용되는 순서는 별개라는 것을 조심해야 해요.

question_id: miniboss_beg_mc_6_2_007
question: 매개변수가 2개 정의된 함수를 호출할 때, 인수의 개수를 다르게 집어넣으면 어떻게 되나요?
choices:
  A. 부족한 인수는 자동으로 0이나 빈 문자열로 처리된다.
  B. 넘치는 인수는 자동으로 무시되고 정상 실행된다.
  C. TypeError 에러가 발생하며 프로그램이 중단된다.
  D. 파이썬이 임의의 임시 값을 만들어 함수를 무조건 실행시킨다.
answer: C
explanation: 특별한 설정(기본값 등)이 없다면 함수의 매개변수 개수와 호출할 때 적는 인수의 개수는 완벽히 일치해야 합니다. 다르면 `TypeError`가 발생합니다.
feedback.correct: 정답입니다! 개수를 지키지 않고 함수를 부르면 파이썬이 화를 내며 실행을 멈춰버려요.

question: 다음 코드를 실행했을 때 발생하는 현상은 무엇인가요?

  def attack(power):
      print(f"{power}의 데미지를 주었습니다.")

  attack("강력", 500)

  A. 강력의 데미지를 주었습니다.
  B. 500의 데미지를 주었습니다.
  C. 강력 500의 데미지를 주었습니다.
  D. TypeError 에러가 발생한다.
answer: D
explanation: `attack` 함수는 매개변수를 `power` 1개만 요구하는데 호출 시 인수를 `"강력"`, `500`으로 2개 넘겨주었으므로 개수가 맞지 않아 `TypeError`가 발생합니다.
feedback.correct: 정답입니다! 인수가 매개변수 개수보다 많아도 문법 오류가 일어납니다.

  def make_profile(id, nickname):

  make_profile(nickname="에이짱", id="user99")

  B. user99(에이짱)
  C. nickname(id)

feedback.correct: 정답입니다! 키워드 인수를 활용하면 순서가 뒤바뀌어도 이름에 맞춰 올바르게 대입됩니다.

feedback.correct: 정답입니다! 변수 매칭 결과를 수식에 대입하면 `30 - 10 = 20`이 도출됩니다.
