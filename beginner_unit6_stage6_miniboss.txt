feedback.correct: 정답입니다! 함수 안에 둥지를 틀어놓은 새끼 함수 같은 개념이에요.

choices:
  A. 내부 함수는 프로그램 어디서든 호출할 수 있는 전역 함수가 된다.
  B. 내부 함수는 자신을 감싸고 있는 바깥쪽 함수 안에서만 원칙적으로 호출하고 사용할 수 있다.

question_id: miniboss_beg_os_6_6_003
question: 다음 코드를 가동시켰을 때 연출되는 출력 화면은 어떤 모습인가요?
code: |
  def outer_func():
      print("바깥쪽")
      def inner_func():
          print("안쪽")
      inner_func()

  outer_func()
choices:
  A. 바깥쪽
  B. 안쪽
  C. 바깥쪽\n안쪽
  D. 안쪽\n바깥쪽
answer: C
explanation: `outer_func()`를 실행하면 먼저 `"바깥쪽"`이 인쇄됩니다. 그리고 이어서 줄 아래에 배치된 내부 호출 코드 `inner_func()`에 신호가 가면서 `"안쪽"`이 연달아 줄바꿈되어 찍힙니다.
feedback.correct: 정답입니다! 외부 함수가 흘러가다가 내부 함수를 직접 구동해 주어 순차적으로 출력되었습니다.

question_id: miniboss_beg_os_6_6_004
question: 다음 코드를 돌렸을 때 도출되는 결과를 골라보세요.
code: |
  def out_wall():
      def in_wall():
          print("비밀 통로")

  out_wall()
choices:
  A. 비밀 통로
  B. out_wall
  C. 에러 발생
  D. 아무것도 출력되지 않는다.
answer: D
explanation: `out_wall()` 함수를 부르긴 했으나, 내부 함수 `in_wall`을 정의(설계)만 해 두었을 뿐, `in_wall()`을 가동하는 실질적 호출 코드가 함수 내외부 어디에도 적혀있지 않습니다. 그러므로 내부 로직이 움직이지 않아 아무것도 안 나옵니다.
feedback.correct: 정답입니다! 내부 함수도 결국 함수이기 때문에 정의만 하고 가동 버튼(호출 괄호)을 누르지 않으면 절대 실행되지 않습니다.

question_id: miniboss_beg_os_6_6_005
question: 다음 코드를 실행했을 때 목격할 수 있는 현상은 무엇인가요?
code: |
  def machine():
      def gear():
          print("위잉")
      gear()

  gear()
choices:
  A. NameError 에러가 발생한다.
  B. 위잉이 두 번 출력된다.
  C. 위잉이 한 번 출력된다.
  D. 무한 루프에 빠진다.
answer: A
explanation: 맨 아랫줄의 `gear()`는 함수 바깥 완전 외딴 벌판(전역)에서 내부 함수 이름을 직격으로 호출하려 시도하고 있습니다. `gear`라는 이름은 `machine` 함수실 내부 전용이므로 외부 전역에서는 보이지 않아 `NameError` 오류가 터집니다.
feedback.correct: 정답입니다! 내부 함수는 은밀하게 격리되어 있으므로 바깥에서 멋대로 월담하여 도적 호출을 감행하면 에러가 납니다.

question_id: miniboss_beg_os_6_6_006
question: 다음 코드의 출력 결과를 올바르게 맞추어 보세요.
code: |
  def master(x):
      def servant(y):
          return y * 2
      return servant(x) + 5

  print(master(10))
choices:
  A. 20
  B. 25
  C. 15
  D. 30
answer: B
explanation: `master(10)` 호출로 `x`에 10이 탑승합니다. 함수 내부에서 `servant(x)` 즉 `servant(10)`을 가동하여 `10 * 2 = 20`을 수령합니다. 그 받아온 20에다가 5를 합쳐 최종적으로 25를 return 하므로 25가 찍힙니다.
feedback.correct: 정답입니다! 외부 함수와 내부 함수 사이에 인수가 평화롭게 순환 전파되면서 수식이 계산되었습니다.

--- Q07 | hard | multiple_choice ---
question_id: miniboss_beg_mc_6_6_007
question: 내부 함수 안에서 바깥쪽 외부 함수의 변수를 수정하려 할 때, global 대신 사용해야 하는 특수 스코프 키워드는 무엇인가요?
choices:
  A. local
  B. main
  C. nonlocal
  D. double
answer: C
explanation: 전역(Global) 변수가 아니라, 자신보다 딱 한 단계 더 넓은 부모 외부 함수의 변수 구역을 타격하여 수정하고 싶을 때는 `nonlocal` 키워드를 써야 합니다.
feedback.correct: 정답입니다! "완전 바깥 전역(global)은 아니지만 내 안방 구역도 아니다"라는 의미의 `nonlocal` 키워드입니다.

--- Q08 | hard | output_select ---
question_id: miniboss_beg_os_6_6_008
question: `nonlocal` 키워드를 장착한 다음 코드의 최종 화면 인쇄 숫자는 무엇일까요?
code: |
  def main_calc():
      num = 10
      def sub_calc():
          nonlocal num
          num = 30
      sub_calc()
      print(num)

  main_calc()
choices:
  A. 10
  B. 에러 발생
  C. 40
  D. 30
answer: D
explanation: `sub_calc` 내부 함수 안에서 `nonlocal num`으로 선언을 마친 후 30을 넣었기 때문에, 부모 함수인 `main_calc` 구역에 살던 `num = 10` 자산이 직접 30으로 교체 변형됩니다. 따라서 하단의 `print(num)` 구문은 30을 배출합니다.
feedback.correct: 정답입니다! nonlocal 덕분에 내부 자식이 부모 방의 변수 데이터를 완벽히 통제하고 변개하는 데 성공했습니다.

--- Q09 | hard | output_select ---
question_id: miniboss_beg_os_6_6_009
question: 다음 중 '클로저(Closure)' 개념맛보기의 원리가 가미된 코드입니다. 출력 결과를 세밀히 정조준하여 골라보세요.
code: |
  def maker(n):
      def helper(x):
          return x + n
      return helper

  my_func = maker(10)
  print(my_func(5))
choices:
  A. 15
  B. 10
  C. 5
  D. 에러 발생
answer: A
explanation: `maker(10)`은 매개변수 `n`에 10을 묶어둔 채 내부 함수인 `helper` 함수의 실체(기능 자체)를 통째로 밖으로 리턴해줍니다. 그 결과 `my_func`는 10을 기억하는 함수가 되며, 여기에 5를 넣어 돌리면 `5 + 10 = 15`라는 마법 같은 조합 결과가 반환됩니다.
feedback.correct: 정답입니다! 함수를 통째로 반환하여 바깥에 저장해두고 마치 도구처럼 조립하여 활용하는 고급 테크닉 기법의 기초입니다.

code: |
  def monster_factory(name):
      def spawn():
          return name + " 출격"
      return spawn()

  print(monster_factory("방해몬"))
choices:
  A. spawn()
  B. 방해몬 출격
  C. name 출격
  D. 에러 발생
answer: B
explanation: 이번에는 내부 함수 자체를 주는 게 아니라 `return spawn()` 즉 함수를 내부에서 미리 돌려버린 최종 '결과물 문자열'을 리턴하고 있습니다. `spawn()`의 작동 결과는 `"방해몬 출격"`이므로 최종 정답은 B입니다.
feedback.correct: 정답입니다! 내부 함수 이름만 리턴하는지, 괄호를 붙여 실행한 결과물을 리턴하는지 그 차이를 구분해야 합니다.
