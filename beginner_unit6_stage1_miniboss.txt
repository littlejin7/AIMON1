question: 파이썬에서 함수(Function)를 사용하는 가장 주된 목적은 무엇인가요?
choices:
  A. 똑같은 코드를 반복해서 쓰지 않고 재사용하기 위해
  B. 프로그램의 실행 속도를 무조건 2배 이상 올리기 위해

question_id: miniboss_beg_os_6_1_004
question: 다음 코드를 실행했을 때 화면에 출력되는 결과는 무엇인가요?
code: |
  def say_hello():
      print("안녕하세요!")
choices:
  A. 안녕하세요!
  B. def say_hello():
  C. say_hello
  D. 아무것도 출력되지 않는다.
answer: D
explanation: `def` 구문은 함수를 정의만 한 단계입니다. 함수를 실제로 실행하려면 `say_hello()`와 같이 호출해야 합니다.
feedback.correct: 정답입니다! 함수를 만들기만 하고 부르지(호출하지) 않으면 내부 코드는 실행되지 않아요.

feedback.correct: 정답입니다! 함수를 호출한 횟수만큼 내부 코드가 정직하게 실행됩니다.

feedback.correct: 정답입니다! 함수 정의부 내부 코드는 호출 신호가 떨어지기 전까지 건너뛰고 진행됩니다.

question_id: miniboss_beg_os_6_1_008
question: 다음 코드를 실행했을 때 발생하는 결과로 옳은 것은 무엇인가요?
code: |
  sing()

  def sing():
      print("랄랄라~")
choices:
  A. 랄랄라~가 정상 출력된다.
  B. 화면에 sing() 문자열이 출력된다.
  C. 아무 일도 일어나지 않고 넘어간다.
  D. NameError 에러가 발생한다.
answer: D
explanation: 파이썬은 코드를 위에서부터 읽어 내려갑니다. 함수가 `def`로 정의되기도 전에 위에서 호출하면 파이썬이 해당 이름을 알 수 없어 `NameError`를 일으킵니다.
feedback.correct: 정답입니다! 함수를 호출하려면 반드시 호출하는 코드보다 윗줄에 함수가 먼저 정의되어 있어야 합니다.

question_id: miniboss_beg_os_6_1_009
question: 다음 코드의 출력 결과를 골라보세요.
code: |
  def stage_1():
      print("하나")

  def stage_2():
      stage_1()
      print("둘")

  stage_2()
choices:
  A. 하나\n둘
  B. 둘\n하나
  C. 둘
  D. 에러 발생
answer: A
explanation: `stage_2()`를 호출하면 내부적으로 `stage_1()`이 먼저 실행되어 "하나"가 출력된 후, 이어서 "둘"이 출력됩니다.
feedback.correct: 정답입니다! 함수 내부에서 이미 만들어진 다른 함수를 호출하는 것도 완전히 가능합니다.

question: 다음 코드에서 "에이몬"이라는 글자가 출력되는 횟수는 총 몇 번인가요?
code: |
  def print_monster():
      print("에이몬")

  for i in range(3):
      print_monster()

  A. 1번
  B. 3번
  C. 2번
  D. 0번
answer: B
explanation: `for i in range(3):` 루프에 의해 내부의 `print_monster()` 함수 호출이 총 3번 반복 실행됩니다.
feedback.correct: 정답입니다! 반복문 속에 함수 호출을 넣으면 함수 내부의 기능을 손쉽게 여러 번 가동할 수 있습니다.
