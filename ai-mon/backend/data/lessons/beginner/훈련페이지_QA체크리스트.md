# 🧪 훈련 페이지 QA 체크리스트 (수동 검증 / 회귀 테스트)

> 자동 테스트(184개)가 못 잡는 UX·상태 전환 영역. 훈련 페이지 변경 시 매번 이걸로 회귀 확인.
> 형식: 한 줄씩 직접 눌러보며 ✅/❌ 표시.

## 1. 레벨 잠금 (Settings 규칙과 동일해야)
- [ ] 내 계정 레벨로 로그인 시 **초급 + 내 레벨만** 열림
- [ ] 권한 없는 레벨칩은 흐리게(opacity 0.4) + 클릭 차단
- [ ] 레벨칩 전환 시 유닛 선택이 전체(null)로 초기화되고 오답/정답률 재조회됨
- 기준: `isLocked = lv.id !== 'beginner' && lv.id !== userCourseLevel` (Settings.jsx와 동일)

## 2. 오답복습 (실제 오답만)
- [ ] 카드의 "N문제 대기"가 **실제 오답 수**와 일치 (전체 풀 크기 아님)
- [ ] 눌렀을 때 **틀린 문제만** 나옴 (정답·미시도 제외)
- [ ] 오답 0개일 때 빈 상태 안내 (셔플 15개로 안 채워짐)
- 기준: stat fetch·진입 둘 다 `only_wrong: true` / 문제별 최신 attempt 1건

## 3. 랜덤퀴즈 (잠금 → 해제 전환 확인)
- [ ] 스테이지 0개 완료 상태: 카드 잠금 + "스테이지 클리어 필요"
- [ ] 스테이지 1개 클리어 후: 카드 열림
- [ ] 열린 뒤 클릭 시 **실제 문제가 출제됨** (빈 결과 alert 아님)
- [ ] 안 배운(미완료) 유닛 문제는 안 나옴
- 기준: `progress.is_completed=True` 유닛에서만 랜덤 N개, 폴백 없음

## 4. 보스특훈 (잠금 → 해제 전환 확인)
- [ ] 미니보스 0개 클리어 상태: 카드 잠금 + "미니보스 클리어 필요"
- [ ] 미니보스 1개 클리어 후: 카드 열림
- [ ] 열린 뒤 클릭 시 **보스 러시 문제 출제됨**
- 기준: `user.miniboss_cleared_stages` 기반, 폴백 없음
- ⚠️ 회귀 주의: 미니보스 클리어 시 `miniboss_cleared_stages`에 실제 append 되는지
  (miniboss.py 기록 지점) — 안 써지면 보스특훈이 영영 안 열림

## 5. attempts 기록 (모드 값 정확성)
- [ ] 각 모드 풀이 후 `attempts` 테이블에 행 생성
- [ ] mode 값이 정확히 저장 (quiz / train / random / boss_rush / unitboss / miniboss / endboss)
  - 회귀 주의: random·boss_rush가 'quiz'로 강등 저장되던 버그 있었음
- [ ] AI 피드백 실패/타임아웃 시에도 오답 기록 남음
- [ ] 유닛별 정답률이 `is_completed`가 아니라 실제 정오답 기반
