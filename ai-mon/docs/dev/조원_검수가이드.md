# 📋 초급(Beginner) 데이터 검수 가이드 — 조원용

> 이 파일 1개 + `detect_format_issues.py` 1개만 보면 됩니다.
> 검수 대상: **레슨 · 퀴즈 · 미니보스** / 원칙: **고치지 말고 기록 → 일괄 수정 → 재확인**

---

## 0. 시작 전 3가지

1. 데이터 구조부터 익히기 (레슨 기준)
   ```
   레슨: lesson_id, unit, stage, title, villain, slides[]
   슬라이드: order, text(설명), terminal{code[], output[]}, tip
   ```
2. 검수는 **파일(유닛) 단위**로 하나씩. unit_1 → unit_8.
3. 발견한 문제는 **직접 수정 X**. 아래 표에 기록만. (구조 건드리면 또 깨짐)

### 기록 양식 (스프레드시트 하나 만들어서 공용)
| 파일 | lesson_id | 위치(order/문항) | 분류 | 심각도 | 내용 | 제안 |
|------|-----------|------------------|------|--------|------|------|

- 분류: `커리불일치` `출력불일치` `코드에러` `포맷깨짐` `정답오류` `오타` `구조깨짐`
- 심각도: **높음**(틀린정답·실행에러·파싱깨짐) / 중간(범위·일관성) / 낮음(표현)
- 직접 수정 OK: 오타·한국어 표현만 / 기록만: JSON구조·code·정답·output

---

## 1단계. 자동 탐지 먼저 돌리기 (눈으로 찾지 말 것)

```
python detect_format_issues.py <레슨/퀴즈/미니보스 폴더경로...>
```
- 퀴즈/미니보스에 처음 돌릴 땐 스크립트 상단 `ANSWER_KEYS`, `OPTION_KEYS`를
  실제 정답/보기 필드 이름에 맞게 한 번만 수정.
- 잡아주는 것: 백틱·마크다운펜스(```)·이중이스케이프·HTML엔티티·
  스마트따옴표·**정답 복수·보기 중복·정답 모호**·텍스트 속 `\n`.
- 나온 목록을 표에 옮기고 각 항목에 `버그 / 정상(의도) / 보류` 표시.

### ⚠️ `\n` 판정 (제일 헷갈림)
- ✅ 정상: `\n`을 **글자로** 보여주려는 것. 예) tip "`\n`은 줄바꿈입니다"
- ❌ 버그: 문단을 **줄바꿈**하려고 넣었는데 화면에 `\n` 글자로 찍힘.
  예) 설명 text 안의 `\n` (현재 unit_6, unit_8에 있음)
- 같은 `\n`이 어디선 되고 어디선 안 되면 → **프론트 렌더 문제**. 개발자에게 같이 보고.

## 2단계. 커리큘럼과 맞는지 대조

각 유닛 레슨 목록(제목·개수·순서)을 커리큘럼 화면과 1:1 비교.
불일치는 3종으로: `누락`(커리O 데이터X) / `초과`(데이터O 커리X) / `내용다름`.

### 현재까지 확인된 것 (참고)
| Unit | 상태 |
|------|------|
| 1,3,4,5,6,7 | ✅ 커리와 일치 |
| **2** | ⛔ JSON 깨짐 → 복구 전 대조 불가 (최우선) |
| **8** | ⛔ 커리(계산기·게임·TODO 등 6개)와 데이터(인벤토리 테마 7개)가 완전히 다름 → 팀 결정 필요 |

---

## 3단계. 내용 검수 (레슨/퀴즈/미니보스 공통 + 개별)

### 공통 (제일 중요)
- 모든 `code`를 **실제로 실행** → `output`과 글자까지 일치하는가
- 그 유닛에서 **배운 범위 안에서만** 나오는가 (안 배운 문법 X)
- 설명·tip이 내용과 맞고 한국어 오타 없는가

### 레슨
- 커리와 제목/개수/순서 일치 (2단계)
- text 설명이 그 슬라이드 code가 하는 일과 맞는가
- villain 캐릭터명 표기가 전 레슨 통일됐는가

### 퀴즈
- 정답이 실제로 맞는가 (코드형은 직접 실행)
- **정답이 1개인가** (복수·중복·모호 → 1단계 스크립트가 잡아줌)
- 오답 보기가 명백히 틀린가, 보기 중복 없는가
- 문항 수·난이도가 초급 적정

### 미니보스 (유닛 마무리 종합)
- 그 유닛 **전체 개념을 종합**하는가 (한 개념 반복 X)
- 정답 코드 실행 → 기대 출력 일치
- 난이도가 레슨보다 약간 높되 초급 범위 안
- villain 스토리/이름 표기 통일, 클리어 판정 로직 명확

## 검수 순서 요약
1. `detect_format_issues.py` 돌려 포맷/정답 문제 자동 추출 → 표 기록
2. 커리큘럼 대조 (2단계) → 불일치 표 기록
3. 코드 실행하며 내용 검수 (3단계) → 표 기록
4. 전부 개발자/Claude Code에 넘겨 일괄 수정 → 스크립트 재실행해 **0건** 확인

> 막히는 부분(특히 unit_2 복구, unit_8 채택 여부)은 팀장에게 보고.
