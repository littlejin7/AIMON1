1. 서비스 개요
1-1. 한 줄 정의
AI-MON은 비전공자와 코딩 입문자가 레슨, 퀴즈, 보스전, 미니게임을 통해 Python과 AI 개발 역량을 단계적으로 학습하는 모바일 중심 웹 서비스입니다.

1-2. 해결하려는 문제
초보 학습자는 다음 지점에서 쉽게 이탈합니다.

개념 설명만으로는 코드를 직접 사용하는 감각을 익히기 어렵습니다.
긴 강의와 반복 문제는 학습 동기를 유지하기 어렵습니다.
오류가 발생했을 때 무엇이 잘못됐는지 스스로 판단하기 어렵습니다.
Python 기초 이후 AI API, LangChain, 에이전트 개발까지 이어지는 학습 경로가 단절돼 있습니다.
학습 결과가 점수 외에는 눈에 보이지 않아 성취감이 약합니다.

코드 작성 문제는 서버 채점 또는 AI 채점을 사용합니다.
오답에는 문제 유형과 학습 레벨에 맞는 피드백을 제공합니다.
보스전, 미션, 랭킹, 캐릭터 진화로 학습 성과를 시각화합니다.
1-4. 핵심 타깃
코딩 경험이 거의 없는 학생 및 성인 비전공자
Python을 처음부터 체계적으로 배우려는 입문자
Python 기초 이후 AI API와 AI 에이전트 제작까지 학습하려는 사용자
강의형 학습보다 짧은 문제와 게임형 진행을 선호하는 사용자
1-5. 브랜드 스토리
AI-MON은 복잡한 AI 기술을 사용자의 편에서 풀어주는 조력자라는 의미를 담습니다.

사용자는 단순히 문제를 푸는 것이 아니라, 학습을 통해 자신의 AI 캐릭터 에이몬을 성장시킵니다. 각 코스의 엔드보스를 클리어할 때마다 에이몬이 진화하며, 최종적으로 AI 개발 역량을 갖춘 학습자로 성장하는 흐름을 표현합니다.

Claude는 다음 상황에 제한적으로 사용합니다.

학습 레벨별 오답 설명

AI 응답 파싱 또는 서비스 호출이 실패하면 다음 원칙을 적용합니다.

오답 패널티를 적용하지 않습니다.
사용자가 동일 문제를 다시 제출할 수 있게 합니다.
채점 실패와 실제 오답을 구분합니다.
서버 로그에는 오류를 남기되 API 키나 민감 정보는 노출하지 않습니다.

9. 랭킹과 칭호
9-1. 랭킹
AI-MON은 목적이 다른 두 종류의 랭킹을 구분합니다.

랭킹	기준
주간 미니게임 랭킹	이번 ISO 주의 게임별 랭킹점수 합계
누적 종합 랭킹	학습·게임·미션·보스에서 획득한 ranking_score
에이팡은 왕관 전용 게임이므로 점수 랭킹에서 제외됩니다.
게임별 Top N, 내 순위, 지난주 우승자를 조회할 수 있습니다.
랭킹 조회는 30초 TTL 캐시를 사용합니다.
현재 게임별 가중치는 모두 1.0이며 실제 분포를 확인한 후 조정할 수 있습니다.

13. 차별점
13-1. 문법부터 AI 에이전트까지 연결된 커리큘럼
기초 문법만 제공하는 것이 아니라 Python, API, 비동기, LangChain, AI 에이전트까지 하나의 성장 경로로 연결합니다.

13-2. 게임 진행과 실제 학습 게이트 결합
단순 포인트 적립이 아니라 서버 채점 결과를 기반으로 다음 스테이지와 보스를 해금합니다.

13-3. 문제 유형별 채점 분리
정답이 명확한 문제는 직접 채점하고, 자유도가 높은 코드만 AI 평가를 사용해 비용과 일관성을 관리합니다.

13-4. 성장·재화·경쟁 지표 분리
소비성 코인, 누적 랭킹점수, 최종 진화 후 GP, 특수 재화 왕관을 분리하여 보상 목적이 서로 충돌하지 않게 설계합니다.

13-5. 서버 권위 보상 구조
게임 점수, 보스 승패, 완료 상태를 클라이언트에 맡기지 않고 서버 토큰과 세션을 기준으로 검증합니다.
