# 🤖 AI MON — 에이몬
# AI 코딩 학습 플랫폼 기획안 | v1.0 | 2026

---

## 1. 서비스 개요

에이몬(AI-Mon)은 Python 기초부터 AI 에이전트 구축까지 게임하듯 재미있게 학습할 수 있는 비전공자 맞춤형 코딩 학습 PWA(프로그레시브 웹 앱)입니다.

### 2. 브랜드 스토리

- **숨겨진 조력자:** 고대 이집트의 신비로운 신 '아몬(Amon)'처럼, 베일에 싸인 복잡한 AI 기술을 비전공자도 쉽게 다룰 수 있도록 돕는 강력한 동반자이자 조력자를 뜻합니다.
- **성장형 육성 게임:** 비전공자에게 코딩은 지루한 공부가 아니라, 나만의 AI 캐릭터 에이몬을 육성하는 게임입니다. 유저는 매일 듀오링고식 파이썬 퀴즈를 풀며 XP를 획득하고, 유닛을 완료할 때마다 에이몬이 진화합니다. Unit 8을 모두 클리어하면, 마침내 최종 진화한 에이몬을 마주하게 됩니다.

### 3. 핵심 타겟

- AI 에이전트를 내 손으로 직접 구현해보고 싶지만, 코딩 경험이 전혀 없어 시작이 두려운 **쌩초보 비전공자 및 성인 입문자**

## 2. 서비스 세계관

> 에이몬의 유저는 단순히 문제를 풀지 않습니다.
> **보스를 쓰러뜨리며 성장하는 개발자**가 됩니다.

### 2-1. 기본 구조

유저는 유닛을 학습하고, 유닛 끝에 **보스**가 등장합니다. 보스를 클리어하면 캐릭터가 성장하고, 인증카드가 생성되며, 포트폴리오에 기록이 쌓입니다.

```
레슨 수강 → 스테이지 퀴즈 → 스테이지 미니보스 → 다음 스테이지
                                                      ↓ (1-1 ~ 1-7 완료)
                                                 유닛 보스 등장 → 클리어
                                                      ↓
                               인증카드 자동 생성 + XP 획득 + 포트폴리오 기록
```

### 2-2. 캐릭터 성장 & 커스텀

- **XP 시스템:** 활동마다 XP 획득 → 레벨업 + 커스텀 아이템 구매 용도
  - 스테이지 퀴즈 클리어 (10문제 세트): 2,000 XP
  - 스테이지 미니보스 클리어: 2,500 XP
  - 유닛 보스 클리어: 3,000 XP
  - 엔드보스 클리어: 15,000 XP
  - 스트릭 보상: 500 ~ 10,000 XP
- **레벨 범위:** Lv 1~30+ (초급 1~10 / 중급 11~20 / 고급 21~30 / 파이널 고스트 달성 시 리미트 해제)
- **캐릭터 진화:** XP가 아닌 **유닛 완료 기준**으로 트리거
  - 초급 엔드보스 클리어 (Lv.10) → slime → robot
  - 중급 엔드보스 클리어 (Lv.20) → robot → speech_bubble
  - 고급 엔드보스 클리어 (Lv.30) → speech_bubble → final_ghost → 리미트 해제
- 획득 XP(코인)으로 **캐릭터 색상 팔레트 · 이펙트 변경** 가능
- **터미널 테마** (색상 스킴, 폰트, 프롬프트 스타일) 잠금 해제 형식으로 제공

### 2-3. 보스 계층 구조

| 보스 종류 | 등장 시점 | XP 보상 | 힌트 |
|---|---|---|---|
| 스테이지 미니보스 | 각 스테이지 끝 | 500 XP | 없음 |
| 유닛 보스 | 유닛 전체 완료 후 | 2,000 XP | 2회 |
| 엔드보스 | 레벨(beginner 등) 전체 완료 후 | 15,000 XP | 없음 |

> 유닛 보스 문제 구성 (유형·난이도·커버 범위): `AI_MON_UNITBOSS_QUESTIONS.md` 참고.

### 2-4. 힌트코인 시스템

- 보스 도전 시 힌트코인 사용 → **AI 힌트 1회 열람** (보스당 최대 2회)
- 엔드보스는 힌트 없음
- 코인은 학습 활동(출석 · 코드 리뷰 · 커뮤니티 기여)으로 획득
- 과금 오해 방지: 무료 획득 경로를 항상 UI 최상단에 명시

### 2-5. 인증 & 명예 보상

**보스 클리어 시 인증카드가 자동 생성됩니다:**
- 캐릭터 이미지 + 닉네임 · 보스명 · 클리어 타임 · 사용 언어 · 날짜 포함
- PNG 다운로드 + 공개 링크 공유 → 인스타그램 · X · LinkedIn 즉시 게시 가능
- **바이럴 루프:** 인증카드 공유 → 신규 유입 → 보스 도전 → 다시 공유

**명예의전당:**
- 기본 뷰는 '나 vs 과거의 나' 성장 타임라인 (전체 랭킹은 선택 노출)
- 초보자 이탈 방지를 위해 절대 랭킹보다 개인 성장 지표를 전면에 배치

### 2-6. 깃허브 연동 & 포트폴리오 (고난이도 보상)

- **깃허브 배지:** SVG 파일 자동 생성 → GitHub README.md 삽입 코드 즉시 제공
- **포트폴리오 대시보드:** 클리어 코드와 아키텍처가 프로젝트 카드로 자동 등록
  - 카드: 프로젝트 개요 · 사용 기술 스택 · 코드 하이라이트 · 클리어 시간
  - 공개 URL 하나로 면접관에게 전체 포트폴리오 공유 가능

> **차별화:** LeetCode · Codewars · Codecademy 등 주요 경쟁사 중 포트폴리오 자동 생성과 깃허브 배지 직접 발급을 동시에 제공하는 플랫폼은 현재 존재하지 않습니다.

### 2-7. 엔드보스 시스템

레벨 전체(Unit 1~8) 완료 후 해금되는 최고 난이도 콘텐츠. **종합 시험 × 3페이즈 배틀** 구조로, 전 범위 랜덤 출제 + 페이즈마다 문제 유형이 에스컬레이션됩니다.

## 3. 서비스 구조

에이몬은 MVP 기준 3개 카테고리, 2단계 이후 4개 카테고리로 구성됩니다.

```
📚 레슨
  └ Unit 1 ~ 8
      ├ Stage 1-1
      │   ├ 브리핑 (개념 설명 슬라이드 + 터미널 + 팁)
      │   └ 퀴즈 → 악당 등장

🔄 훈련 (유닛 클리어 후 열림)
  └ 오답 복습 + 유닛 전체 반복 학습

🎮 미니게임 (MVP 이후)
  ├ 게임 A: 타임킬링 (애니팡 스타일) → 왕관 획득
  └ 게임 B: AI 지식 게임 (카드배틀 / OX 등) → XP 100~300 획득 (난이도별 차등)

🧑 내 캐릭터
  └ 에이몬 진화 현황 · 커스텀
```

## 4. 핵심 기능

### 📚 레슨 (Lesson)

- **개념 학습:** 유닛별 개념 설명 + 예제
- **스테이지 퀴즈 (개념퀴즈):** 스테이지별 10문제 · Set A/B 구조 · 60% 이상 통과 시 미니보스 진입
  - 60% 미만 시 재시도: 1회차 Set A → 2회차 Set B → 3회차~ A+B 혼합 랜덤
- **스테이지 미니보스:** 스테이지 끝 관문 · 10문제 · 70% 이상 통과 시 다음 스테이지 잠금 해제
- **유닛 보스 (HP 배틀):** 스테이지 1-1~1-7 전부 완료 후 등장
  - 내 HP 1000 vs 보스 HP 1000
  - 정답 시 보스 HP -150 / 오답 시 내 HP -350
  - 7문제 전부 맞추면 클리어 / 3번 틀리면 실패
  - 클리어 시 XP 3,000 + 레벨업 체크 + 인증카드 자동 생성
- 오답 시 **Claude AI가 왜 틀렸는지 설명** → 핵심 차별점
- 브라우저 내 Python 실행: **Pyodide** (WASM 기반, 서버 엔드포인트 없음)

### 🔄 훈련 (Training)

- 유닛 단위 전체를 커버하는 퀴즈 세트
- 틀렸던 문제 중심 **오답노트 자동 큐레이션**
- **스트릭(Streak)** 시스템 — 매일 접속 시 +1, 하루 빠지면 0 리셋
- 스트릭 달성 시 XP + 왕관 자동 지급 (3일 500XP / 7일 2,000XP+왕관1 / 14일 5,000XP+왕관2 / 30일 10,000XP+왕관5)

### 🧑 내 캐릭터

- 유닛 진행에 따른 **에이몬 진화 현황** 확인
- 획득 코인으로 캐릭터 색상 · 이펙트 커스텀
- 터미널 테마 잠금 해제 (MVP 이후)

## 5. 커리큘럼

> **3개 레벨 / 각 8개 유닛** 구성. 레벨마다 커리큘럼 주제가 완전히 다릅니다.
> - **초급 (beginner):** 파이썬을 한번도 안 써본 사람 — 1~2달
> - **중급 (intermediate):** 초급 완료 후 실용 코드 짜고 싶은 학습자
> - **고급 (advanced):** 중급 완료 후 실무 & AI 활용을 목표로 하는 학습자

## 9. MVP 범위

> 기간 내 제출 가능한 수준으로 기능 컷.

**✅ MVP 필수 (이것만 완벽하게)**
- 비로그인 사용자는 /level-test-info 안내 페이지 노출 → 회원가입 유도
- 로그인 사용자 한정 레벨 테스트 제공 및 대시보드 레벨 배지 노출
- 스테이지 퀴즈 풀기 (Set A/B 각 10개, 60% 이상 통과 시 미니보스 진입)
- 미니보스 풀기 (5개, 70% 이상 통과 시 다음 스테이지)
- 정답 시: explanation 필드 텍스트 출력 (API 호출 없음)
- 오답 시: Claude AI 피드백 설명 (레벨별 다름) → **핵심 차별점**
- 진도 추적 (progress.json, 플랫 배열 구조)
- XP + 레벨업 (Lv 1~30+, 레벨 × 1,000 XP)
- 왕관 획득 (유닛 완료 시 유닛 번호만큼 지급, 중복 방지)
- 유닛 보스 도전 (HP 배틀, 하루 2회 무료, 이후 왕관 소모)
- 캐릭터 진화 (초급/중급/고급 파이널 보스 Lv.10/20/30 달성 기준)
- 훈련 (오답 우선 + 랜덤 15문제, 유닛 선택 가능)

**⬜ 나중에 (MVP 이후)**
- 훈련(복습) 시스템 · 오답노트
- 인증카드 · 포트폴리오 자동 완성
- 스트릭 보상 · 커스텀 아이템
- 파이널 보스
- 미니게임 카테고리 (네비바 4탭 확장)
  - 게임 A: 타임킬링 (애니팡 스타일) → 왕관 획득
  - 게임 B: AI 지식 게임 (카드배틀 / OX 등 2~3종) → XP 100~300 획득 (난이도별 차등)
- 리더보드 · 친구 기능 · 커뮤니티
- 깃허브 배지 연동
