question_id: miniboss_beg_os_6_7_003
question: 그동안 배운 지식을 활용하여 다음 복합 연산 코드를 실행했을 때 드러나는 출력 숫자는 무엇일까요?
code: |
  def calc_magic(a, b):
      return (a + b) * 2

  x = calc_magic(3, 4)
  y = calc_magic(1, 2)
  print(x - y)
choices:
  A. 5
  B. 14
  C. 8
  D. 4
answer: C
explanation: `calc_magic(3, 4)`는 `(3 + 4) * 2 = 14`이므로 `x = 14`입니다. `calc_magic(1, 2)`는 `(1 + 2) * 2 = 6`이므로 `y = 6`입니다. 결과적으로 `14 - 6 = 8`이 최하단에서 출력됩니다.
feedback.correct: 정답입니다! 수식 계산에 함수 호출 결과를 각각 적용하여 대입 연산을 순차적으로 해결했습니다.

feedback.correct: 정답입니다! `len()` 내장 함수와 사용자 함수가 서로 얽혀서 최종 숫자 18을 계산해 냈습니다.

question: 리스트 자료구조 내부 원소들의 총합을 구하는 복합 함수형 제어 코드입니다. 출력 결과를 골라보세요.

  def sum_all_elements(numbers):

          total += num
      return total

  items = [10, 20, 30]

  B. 30
  C. 60
  D. [10, 20, 30]

feedback.correct: 정답입니다! 유닛 4, 5에서 핵심적으로 다루었던 리스트 누적 순회 순환 알고리즘이 함수 제어식으로 멋지게 마감되었습니다.

  def filtering_list(words):
      selected = []
      for w in words:
          if len(w) >= 4:
              selected.append(w)
      return selected

  sample = ["cat", "tiger", "lion", "dog"]
  print(filtering_list(sample))

  B. 4
  C. ["tiger"]
  D. ["tiger", "lion"]

feedback.correct: 정답입니다! 함수를 활용하면 특정 조건으로 데이터를 감별하여 걸러내는 맞춤형 가공 기계 장치를 직접 설계할 수 있습니다.

question_id: miniboss_beg_os_6_7_009
question: 다음 코드의 최종 결과를 예측하여 보세요.
code: |
  def transform(n):
      if n % 2 == 0:
          return n * 10
      return n + 100

  def multi_process(data_list):
      result = []
      for item in data_list:
          result.append(transform(item))
      return result

  print(multi_process([2, 3]))
choices:
  A. [20, 103]
  B. [2, 103]
  C. [20, 3]
  D. [22, 103]
answer: A
explanation: `multi_process` 함수는 받은 리스트 요소를 하나씩 꺼내어 다시 다른 전용 함수인 `transform`으로 통과시킵니다. 2는 짝수이므로 `2 * 10 = 20`이 되고, 3은 홀수이므로 `3 + 100 = 103`이 됩니다. 이 가공된 데이터가 모여 `[20, 103]` 리스트 형태로 리턴됩니다.
feedback.correct: 정답입니다! 하나의 커다란 함수가 자신의 일을 완수하기 위해 세부 전용 함수에게 처리를 위임 배스하는 유기적 협업 실무 코드 패턴입니다.

question: 다음 고난이도 종합 실습용 파이썬 구문의 실행 결과는 무엇인가요?
code: |
  def add_deco(word):
      return "***" + word + "***"

  def print_report(title, check=True):
      if check:
          final_title = add_deco(title)
      else:
          final_title = title
      print(final_title)

  print_report("에이몬 보스", check=True)
choices:
  A. 에이몬 보스
  B. ***에이몬 보스***
  C. ***title***
  D. 에러 발생

explanation: `print_report` 함수에 `"에이몬 보스"`와 `check=True`를 전달했습니다. `if check:` 조건 관문이 참이 되므로 `add_deco("에이몬 보스")`가 작동하여 양옆에 별표가 붙은 `"***에이몬 보스***"` 문자열이 `final_title`에 이식되어 깨끗하게 출력됩니다.
feedback.correct: 정답입니다! 함수의 기본값 활용, 분기문, 문자열 가공 기능이 총집대성된 문제였습니다. 유닛 6 코스를 마침내 완벽히 독파하셨습니다!
